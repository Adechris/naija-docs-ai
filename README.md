# Naija Docs AI

Build **DocuAI** — a premium AI-powered business document 

generation SaaS platform specifically built for Nigerian 

businesses, professionals, and freelancers. Users input 

basic information and AI instantly generates professional, 

legally-aware, Nigerian-context documents they can 

download, edit, and share.

This is NOT a generic document tool. DocuAI is deeply 

Nigerian — it understands Nigerian Labour Act, CAC 

requirements, Naira formatting, Nigerian business culture, 

and local market context. That is the competitive 

advantage over ChatGPT and foreign alternatives.

The app has three parts:

1. **Public Landing Page** — marketing and signup

2. **User Dashboard** — generate and manage documents

3. **Admin Dashboard** — manage users, subscriptions, 

   and platform analytics

Design: Clean, professional, corporate — 

white and blue. Feels like Notion meets 

DocuSign meets a Nigerian fintech product.

## ⚙️ FRONTEND ARCHITECTURE

- React + TypeScript + Vite

- React Router v6 for ALL routing

  (createBrowserRouter, protected routes,

   nested layouts)

- All API calls in `/src/services/api.ts`

- All Claude AI calls in 

  `/src/services/claudeAI.ts`

- Base URL from `.env`: 

  `VITE_API_BASE_URL`

  `VITE_CLAUDE_API_KEY`

- TanStack Query for data fetching

- Axios with Bearer token interceptor

- Zustand for auth state

- Realistic mock data in `/src/mock/`

- Skeleton loaders on all data components

- Sonner toast notifications

- Framer Motion for animations

### Claude API Call Pattern

```javascript

// /src/services/claudeAI.ts

const callClaude = async (

  systemPrompt: string,

  userMessage: string

): Promise<string> => {

  const response = await fetch(

    "https://api.anthropic.com/v1/messages",

    {

      method: "POST",

      headers: {

        "Content-Type": "application/json",

        "x-api-key": 

          import.meta.env.VITE_CLAUDE_API_KEY,

        "anthropic-version": "2023-06-01"

      },

      body: JSON.stringify({

        model: "claude-sonnet-4-6",

        max_tokens: 4000,

        system: systemPrompt,

        messages: [{

          role: "user",

          content: userMessage

        }]

      })

    }

  );

  const data = await response.json();

  return data.content[0].text;

};

```
